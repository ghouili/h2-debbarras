# Submit sitemap to Google Search Console

1) Open Google Search Console and add a property (Domain property recommended).
2) Verify ownership (DNS TXT record is typical for Domain property).
3) In the left menu, open **Sitemaps**.
4) Submit the sitemap URL:
   - https://debarras-aurea.fr/sitemap.xml
5) Check status for errors and fix any reported issues.
6) Use **URL Inspection** for key pages if needed.
